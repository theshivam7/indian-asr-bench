# Archived: listening notes on the worst TIE clips

Exploratory notes from listening to the 20 highest-WER TIE clips per Whisper model, made
before the results tree was namespaced by dataset. Not maintained and not referenced by
the main documentation.

- `top20_audio_reference.md`: the listening notes.
- `extract_top20_audio.py`: the script that exported those clips. It is frozen and no
  longer runs as-is (it expects the old `results/stage2_processed/` layout and a
  `~/hf_cache` directory).
